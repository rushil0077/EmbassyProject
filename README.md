# Solar Maze Escape
Solar Maze Escape is a browser based maze game that was created by using HTML, CSS, and JavaScript. The goal is to navigate the red ball to the final green cube. There are five different modes. It includes questions about the solar system, making it a science related game.

- There are five game modes: Normal Mode, Solar System Mode, Hard Mode, Timer Mode, Coin Mode
- In normal mode, the red ball has to complete the maze 3 times to win.
- In Solar System Mode, the user has to collect five planets and finish the maze. Once a planet has been picked up, a question about the solar system is asked.
- In hard mode, the maze is bigger and harder to complete. It requires the user to complete the maze three times to win.
- In timer mode, the maze must be completed in under 30 seconds.
- In coin mode, the user must collect 5 modes and complete the maze to win.
- Use WASD or Arrow Keys to move.
